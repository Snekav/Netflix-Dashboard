
# 📊 Streaming Analytics And Network Insights On Netflix – A Tableau Dashboard

This project focuses on analyzing Netflix streaming performance, user behavior, device usage, and technical quality across various dimensions using Tableau. By leveraging key metrics and visualizations, it uncovers insights into how users interact with the platform, the quality of streaming experiences, and network performance issues like buffering.


## Key Features
### KPIs (Key Performance Indicators)
Total Active Users → Count of users with active status.

Cancelled Users → Count of non-renewing users.

Average Buffering Time → Overall buffering experience.

4K Streaming Users → Percentage of users streaming in highest quality.

### Visualizations
Donut Charts → User distribution by payment methods and renewal status.

Bar Charts (Horizontal) → Devices with most buffering issues.

Line Chart → Trend of average buffering time by year.

Map → (If location data used) Internet speed or buffering by region.

Top N Users by Buffering → Using parameters and filters.

## 🧰 Tools Used

Tableau for visualization and dashboard creation.

Microsoft  CSV as the data source.

KPIs and Charts: Line charts, donut charts, horizontal bar charts, maps, KPIs, filters, and parameters.
## 🧠 Tableau Techniques Used


COUNT() – Used to calculate the number of users (e.g., total active users).

AVG() – Calculates average values such as buffering time or internet speed.

Filters – Narrow down data by dimensions like Time of Day, Year, Device, or Payment Method.

Parameters – Allow users to dynamically select and view Top N records (e.g., Top N users with highest buffering).

Dual Axis – Used to create donut charts by overlaying a white circle on a pie chart.

Color Encoding – Applies color gradients to show performance (e.g., red for poor buffering, green for optimal speed).
